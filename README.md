# Big Bang Timeline

Interactive visualization of cosmic history — from quantum fluctuations to the present solar system.

Built as a single-page canvas experience with GSAP timeline scrubbing, a NASA-style expanding funnel, CMB afterglow (WMAP), and an evolving solar system.

## Local

```bash
npm run dev
```

Open http://localhost:3000

## Deploy

```bash
npx vercel --prod
```

## Controls

- Play / scrub — bottom transport
- Scroll on scrubber — zoom timeline range
- Drag canvas — orbit camera
- 1 / 2 / 3 — Diagram / Orbit / Present views
- Space — play/pause
